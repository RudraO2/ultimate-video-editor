# History of the build

Moved verbatim from the Status section of `CLAUDE.md` on 2026-10-29, to keep the file every chat loads small. It records each step of phase A: what was built, in which files, under which names, and the decisions taken. Search it before changing a feature.


- **Done:**
  - A1: scaffold.
  - A2: document model, command API and undo.
  - A3: renderer.
  - A4: media import (`uve-media://` protocol, mediabunny metadata), preview frames and audio, timeline editing (drag, trim, split, snapping, zoom), editable inspector with key diamonds.
  - A5: export to MP4 (H.264 + AAC) with an Export button (Ctrl+E), a progress dialog and Cancel. Frames come from the mediabunny `ExportSources`; the sound is mixed by the engine's `mixLayer` (speed changes pitch, volume up to 400 %). Checked against the preview frame by frame.

    - Theme tokens in `styles.css`, floating panels, and left and right rails (`Rail.tsx`).
    - Library, Media and Layers tabs, and entrance-animation presets.
    - Viewport tools (Move drag, Hand, Text, Rectangle, Ellipse), the zoom pill and pan.
    - The AtomCut-style transport, and track eye, mute and lock (`track.update`), plus `project.update`.
  - A5c: the timeline views and preset library, from REA captures of the live app.
    - Bottom tabs: Timeline, Keyframes (dope sheet), Curves (graph editor), Color (empty state), Nodes (read-only graph). Code in `components/KeyViews.tsx` and `components/PanelViews.tsx`.
    - The mixer meter, Record keyframes (`propertyEdit` in `store.ts`) and Loop.
    - The AtomCut-style inspector: paired axis rows, end-of-row diamonds, collapsible sections.
    - The catalog-driven Library: `library/` holds `atomcut-catalog.json`, `catalog.ts`, `fonts.ts` (Google Fonts, allowed in the CSP) and `sounds.ts`.
  - A6: agent listening over MCP.
    - `packages/mcp`: our own Streamable HTTP server (JSON replies, no event stream; bearer token, loopback Host and Origin checks, sessions) and the `uve-mcp` stdio shim (`bin/uve-mcp.mjs`).
    - `main/agent.ts`: port 7428 (`UVE_MCP_PORT`), token and URL in `~/.uve/mcp.json`, the shim copied to user data, `uve_status`, `report_issue` (local file), file grants for `media_import`, skill docs from `skill/` as `uve://skill/…` resources. Calls go to the renderer over IPC (`agent:call` / `agent:result`).
    - `renderer/src/agent/`: every registry command as a tool, plus `view_render`, `view_frames`, `history_undo`, `media_import` (`host.ts`) and the desktop commands `catalog.list`, `catalog.get`, `session.set`, `app.console` (`commands.ts`).
    - An agent's calls within 45 s are one undo step ("Agent · <app>") via `session.call(name, input, {group, label})`.
    - Command inputs are strict (`z.strictObject`): unknown fields are errors.
    - The Agents rail tab (`components/AgentsPanel.tsx`) with "Connect your agent", modelled on AtomCut's dialog.
    - Checked: headless Claude Code (Sonnet) built a 5 s title card through MCP in 10 turns.
