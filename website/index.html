Ultimate Video Editor turns a sentence into edits on a real timeline. Every layer, key and cut it makes is yours to open, change and undo.

Most AI video is a black box.

You type a prompt, wait, and get a file. If one word is wrong, you regenerate the whole thing and hope. There is no timeline, no keyframe and no way in.

We have all been there.

final_final_v7.mp400:15
SUMER SALENo layers
Regenerating…3 credits left

So you open a pro editor.

Graph editors, expressions, forty panels and a render queue. You could spend a month learning one, or pay someone who already did (goodbye, budget).

Or wire a chatbot to ffmpeg and squint at whatever comes out.

Expressions Pre-comps Graph editor Render queue Track mattes Due Friday

Now there is a third way.

Ultimate Video Editor is a desktop motion editor where every button is also a command, and every command is an agent tool. The agent edits the same project you do, one undo step per request, and you can take over halfway through a sentence.

Give it a sentence. Your evenings will thank you.

Easy and Advanced

Every tool works
by hand, too.

Easy mode is chat, preview and a simple timeline. Advanced mode is every panel. Both edit the same project, in Cream or Dark.

Cream Dark

Drag across the picture to switch themes.

  • Free and open source

    MIT licensed. Download it once and it is yours.

  • One undo step per request

    An agent’s whole turn is one history entry. A failed command leaves the project as it was.

  • Keys on everything

    Every property animates, with a dope sheet, a graph editor and motion paths.

  • Assets included

    4,555 CC0 sounds, about 3,300 stickers, about 413,000 icons and 1,946 font families.

  • Nine export formats

    MP4, MOV master, WebM, GIF, PNG sequence, stills and WAV. Exports with sound report their loudness.

  • Preview matches export

    One renderer for both, physics without baking and seeded scripts, so the file is the frame you saw.
